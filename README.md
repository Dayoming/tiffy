> 남은 식재료를 나누어서 환경과 건강, 우리 집 냉장고도 지키는 일석삼조 프로젝트


## 기능 소개
### 교환 게시판
현재 위치 기반으로 근처(거리 계산 기능 구현 예정)에 있는 사용자들의 게시글을 우선으로 보여줍니다.
게시글을 올려 특정 식재료의 교환 의사를 밝히고, 해당 게시글을 본 사람들이 해당 작성자에게 채팅을 보내 교환 장소를 정할 수 있는 방식입니다.

### 채팅
웹소켓을 사용한 양방향 1:1 채팅 기능입니다. 사용자 닉네임을 검색해서 채팅을 시작할 수 있습니다.

### 레시피 검색
공공데이터포털의 조리식품의 레시피 DB(https://www.foodsafetykorea.go.kr/api/newDatasetDetail.do) 를 활용해 특정 식재료를 입력하면 해당 식재료가 재료로 포함되는 요리 목록을 보여줍니다.
사용자는 해당 정보를 참고하여 남은 식재료 혹은 나눔 받을 식재료를 사용해 어떤 요리를 할지 생각해볼 수 있습니다.
